# CAFE YAYO — recette paie (phase 3 / déjà en place)

La paie Coccinelle (présences, bulletins, journal de transactions) est **en avance** sur le CDC phase 1. Elle n’est pas un livrable Y1 : on la garde, on la recette.

## Parcours

1. Hub département → Personnel / Paie.
2. Marquer une présence (ou encaisser : présence auto depuis l’activité).
3. Générer un bulletin.
4. Journal des transactions (espèces / Mobile Money / banque).

## Hors livrable Y1

Ne pas présenter la paie comme exigence de recette campus. Les profils vendeur / agent production voient « Ma paie » ; PCA / comptable voient le journal.
